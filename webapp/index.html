Slope and slip sphere

Off by default (thesis grid). Needed for circles that cross the toe level behind the toe (xc ≤ 0), exit on the floor ahead of the toe, or stay above the toe level (face circles, R ≤ zc). Toe at the origin; the slope rises towards −x.

Tension sensitivity

Trial-stress projection (thesis Section 4.6) is always on; a run is accepted only if no base is projected at convergence. C0 and T0 act on bases with σn < 0 and are sensitivities, not a calibrated contact law.

This page solves with engine.js, a line-for-line port of ejc_app/engine.py. On 148 analyses (every main case, GHB, FM, C0/T0, the native v15 path, Carranza-Torres, Law and D'Esterre presets, input errors) and 63 strength fixtures the port matches the Python engine: largest FoS difference 4.4 × 10−16 (relative), with the same iteration counts, projection counts and check results.
